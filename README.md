# DuoFuel

Локальное приложение для расхода бензина и LPG. Один автомобиль, без аккаунта и без сети.

Расход каждого топлива считается по закрытому циклу «полный бак → полный бак»: объём открывающей заправки не входит, заправки после неё и закрывающая заправка входят. Литры на 100 км — этот объём, делённый на разность одометров цикла и умноженный на 100. Средний расход — та же формула по сумме закрытых циклов с положительной дистанцией. Неизвестный остаток не подставляется нулём. На ноль и на разорванную шкалу одометра расход не делится.
